# Divine Collection

A responsive premium e-commerce storefront for spiritual, temple and decorative products in Malaysia.

## Front-end

The customer and admin interfaces are framework-free:

- `index.html` — semantic page shell and metadata
- `styles.css` — complete responsive design system
- `app.js` — catalog, navigation, filters, wishlist, cart, checkout and admin interactions

No React, Next.js, Tailwind or front-end runtime dependencies are used.

## Commands

```text
npm run dev
npm run build
npm test
```

The optional Drizzle schema and migrations model customers, products, categories, carts, wishlists, orders, addresses, payments, reviews, coupons and admin users for later backend integration.
